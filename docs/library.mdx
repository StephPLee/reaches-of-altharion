# Spell Library

<div className="doc-prose-panel">

Find out which characters know a spell so you can ask to copy it into your own spellbook. To add your character's spells, run `!sb all` in Discord, right-click Avrae's reply and choose **Copy Message Link**, then run `/spellbook <link>`. Running it again replaces that character's list.
