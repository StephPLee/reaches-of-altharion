Use this page for guidance on reviewing, balancing, and submitting homebrew for the server.

## Workshop Discussions

Homebrew should be discussed in the workshop before it is submitted for approval.

When reviewing homebrew, consider how it compares to existing server options, whether it creates unclear rules interactions, and whether it gives one character option too much power or flexibility.

When the homebrew is ready, use the submission post for final votes and link back to the workshop discussion.
